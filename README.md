# Tannor Freight & Logistics — website

Static one-page site for Tannor Freight & Logistics Ltd. (freight forwarding and customs clearance, Tema/Accra).

- `index.html` — page content
- `css/styles.css` — styles (navy theme; add `data-theme="teal"` on `<html>` for the teal variant)
- `js/main.js` — slideshow, services tabs/accordion, question answers, WhatsApp forms, sticky header
- `assets/` — photos, videos and logos

No build step. To preview locally:

```sh
python3 -m http.server
```

then open http://localhost:8000.

Hosted with GitHub Pages from the `main` branch.

Before launch: replace the sample stats and reviews in the "Why Tannor" section, and add the real Instagram/TikTok links in the footer.
